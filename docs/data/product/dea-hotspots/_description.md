## Product description 

Hotspots provides a record of thermal activity detected across Australia using data from multiple satellites. Satellite sources have different coverage, observation frequencies and spatial resolutions, providing complementary information about heat detected across the Australian landscape. 

Hotspot detections may indicate fires or other sources of heat. Current and historical hotspot information can be used to monitor and analyse thermal activity over time. 

## Intended use 

Hotspots is intended to support monitoring and analysis of thermal activity. It can be used as one of multiple sources of information for emergency preparedness, environmental monitoring and research.

## Supporting documents 

For more detailed technical information, view the [Hotspots Product Description and other supporting documents](https://hotspots.dea.ga.gov.au/files/documents).
